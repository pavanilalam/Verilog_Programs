# Sequential Circuits

This folder contains Verilog HDL implementations of basic sequential circuits.

## Programs

- D Flip-Flop
- SR Flip-Flop
- JK Flip-Flop
- T Flip-Flop
- D Latch
- SISO Shift Register
- SIPO Shift Register
- PISO Shift Register
- PIPO Shift Register
- Ring Counter
- Johnson Counter
- Asynchronous Counter
- Synchronous Counter
- MOD-10 Counter
- MOD-16 Counter
